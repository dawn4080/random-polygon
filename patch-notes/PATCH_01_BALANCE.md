# Random Polygon — 1차 밸런스 패치 정리

> 상태: **1차 밸런스 패치 완료 / 플레이 테스트 단계**  
> 기준 브랜치: `main`  
> 패치 마무리 기준: 2026-09-01

## 핵심 목표

- 초반 난이도 완화
- 적 생성 간격 완화
- 타워별 역할 재정립
- 합성을 통한 장기 성장 강화
- 사각형을 원거리 취약 지원형으로 변경
- 연구 편의성 개선
- 전설 재료 보호를 위한 합성 잠금 추가
- 기어 연쇄 이펙트 최적화

## 웨이브/경제

- 일반 웨이브 적 수: 22 → **20마리 고정**
- 시작 골드: 150G → **180G**
- 적 생성 간격:

```js
Math.max(18, 30 - Math.floor(wave * 0.4))
```

- 마지막 적 소환 후 고정 대기시간이 지나면 다음 웨이브 시작
- 기존 적이 남아 있어도 다음 웨이브 시작 가능
- `INTER_DELAY = 360` 유지
- `MAX_ENEMIES = 100` 유지
- 기지 HP 시스템 없음

## 타워 역할

| 타워 | 역할 | 레벨당 데미지 성장 |
|---|---|---:|
| ▲ 삼각형 | 빠른 단일 딜러 | +20% |
| ■ 사각형 | 원거리 취약 지원 | +22% |
| ★ 별 | 광역 딜러 | +20% |
| ⚙️ 기어 | 전설 연쇄 딜러 | +25% |

최종 데미지 공식:

```text
round((기본 데미지 + 연구 데미지) × (1 + 성장률)^(타워 레벨 - 1))
+ 골드 데미지 보너스
```

현재 골드 데미지 계수는 `GOLD_DMG_RATE = 0.0004`이며 0.1% 상향안은 이번 패치에 적용하지 않았다.

## 사각형 취약

- 기본 취약: +10%
- 타워 레벨당: +2%p
- `약점 분석` 연구당: +3%p
- 기본 지속시간: 3초
- `정밀 분석` 연구당: +1초
- 보스에도 적용
- 여러 취약 효과는 단순 합산 중첩하지 않음

## 연구 편의성

연구소에서 현재 → 다음 수치를 표시한다.

- 데미지
- 사거리
- 공격속도/공격간격
- 폭발 반경
- 기어 연쇄 횟수
- 사각형 취약 효과/지속시간

연구 버튼은 약 420ms 이상 누르면 약 120ms 간격으로 연속 연구한다. 골드가 부족하면 중단한다.

## 합성 잠금

선택한 타워를 합성 잠금할 수 있다.

- 자동합성 제외
- 수동합성 제외
- 이동 가능
- 전설 연성 재료 사용 가능
- 필드에 🔒 표시
- 단축키 `L`

## 전설 기어 연성

최종 조합식:

```text
▲ 삼각형 Lv.7
+ ■ 사각형 Lv.6
+ ★ 별 Lv.5
= ⚙️ 전설 기어
```

정확한 레벨만 인정한다. 목표 레벨을 넘지 않도록 합성 잠금을 사용한다.

## 기어 최적화

- 연쇄 구간당 단순 선 1개 표시
- `shadowBlur` 제거
- `setTimeout` 재귀 연쇄 제거
- 동기 반복 처리
- 이미 맞은 적은 `Set`으로 관리
- 폭발 표시시간 단축
- 단순 기어 탄환 표시

게임플레이상의 연쇄 횟수와 데미지를 약화시키기 위한 변경이 아니라 렌더링 비용 감소가 목적이다.

## 유지한 핵심 규칙

- 순환형 적 경로
- 기지 체력 없음
- 살아 있는 적 100마리 도달 시 게임 오버
- 5웨이브마다 보스
- 보스 제한시간 60초
- 보스 처치 후 난이도 배율 ×1.15 누적
- 소환 확률: 삼각형 58%, 사각형 27%, 별 15%, 기어 0%

## 2차 패치 전 테스트

웨이브 1~20 이상을 실제 플레이한다.

확인 대상:

1. 웨이브 1~5 난이도
2. 첫 보스 난이도
3. 웨이브 10~20 적 누적 압박
4. 각 타워의 역할 체감
5. 취약 효과의 과도함 여부
6. 전설 제작 시점
7. 사각형 Lv.6 재료 난이도
8. 합성 잠금 정상 작동
9. 기어 다수 배치 시 렉
10. 장기 보스 난이도 성장
11. 적 100마리 패배 조건의 체감

이 테스트 이후 수치 변경부터 **2차 밸런스 패치**로 기록한다.
