# RP 패치 기록

이 폴더는 Random Polygon의 완료된 패치 내용을 상세하게 보관한다.

## 규칙

- 패치가 끝날 때마다 이 폴더에 별도 Markdown 문서를 추가한다.
- 상세 수치, 변경 이유, 공식, 테스트 기준은 패치 문서에 기록한다.
- `PROJECT_CONTEXT.md`에는 현재 개발에 반드시 필요한 핵심 상태와 최근 패치 요약만 남긴다.
- 새 채팅에서는 먼저 `PROJECT_CONTEXT.md`를 읽고, 과거 패치의 상세 내용이 필요할 때만 이 폴더의 문서를 확인한다.
- 패치 파일명은 `PATCH_01_BALANCE.md`, `PATCH_02_....md` 형식을 기본으로 한다.

## 패치 목록
